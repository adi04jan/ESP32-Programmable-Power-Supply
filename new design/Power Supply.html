Experimental

Features that aren't fully baked. Toggle at your own risk.

Fast sampling (250 ms) Higher cadence ADC reads. Slightly more CPU on the controller.
Voltage smoothing EMA filter on the readout for a calmer number.
Rotary dial input Drag-to-set knob on the variable channel. Hold Shift for fine 10 mV steps.

Calibration

Sweeps CH1 across all 128 wiper steps to build the step→voltage map used for fast, accurate set-points. Disconnect any load from CH1 first — the output ramps to its maximum during the sweep (~1 min).

WebSocket API

Direct real-time control — useful for automation scripts, Python notebooks, or custom dashboards. No auth header needed if you include the token in the message body.

Endpoint
ws://voltbench.local/ws 
{"output1":true,"output2":false,"output3":false,
"voltage1":5.00,"voltage2":5.01,"voltage3":3.30,
"set1":5.00,"cal":true,"state":"frozen","ts":12345}
// Toggle output  (output 1-3, value true/false)
{"action":"toggle","output":1,"value":true,"token":"YOUR_TOKEN"}

// Set variable voltage  (volts, channel 1 only)
{"action":"set_voltage","output":1,"value":5.0,"token":"YOUR_TOKEN"}

// All outputs off
{"action":"all_off","token":"YOUR_TOKEN"}
